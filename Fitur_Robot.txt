# ==============================================================================
# BUKU PANDUAN FITUR, PARAMETER & CONTOH INPUT - SIMULASI ROBOT OMNI & GUI CONTROLLER
# ==============================================================================

Berikut adalah daftar lengkap fitur, cara menjalankan, panduan parameter 
(Vx, Vy, Vw, Limit, Keterangan), serta CONTOH PENGISIAN INPUT dan EFEK GERAKAN 
pada masing-masing fitur simulasi robot omni & GUI controller.

------------------------------------------------------------------------------
A. CARA MENJALANKAN SIMULASI & GUI CONTROLLER
------------------------------------------------------------------------------

1. Menjalankan Simulator Pygame:
   - Jalankan script simulator (`simul_jalan.py` atau `main.py`).
   - Simulator akan membuka layar arena Pygame, menginisialisasi robot omni, 
     dan membuka server Socket komunikasi (port 5005).

2. Menjalankan GUI Controller:
   - Jalankan GUI controller (`gui_controller.py` atau `python -m gui.app`).
   - Pastikan indikator koneksi di GUI menunjukkan status "Connected".

3. Menjalankan Sekuens Gerakan:
   - Pilih / susun "Urutan Kombinasi" dan "Antrean Kombinasi".
   - Klik tombol "Mulai" (Start) untuk mengeksekusi sekuens.
   - Gunakan tombol "Start From" jika ingin mulai dari tahapan tertentu yang disorot.

------------------------------------------------------------------------------
B. PENJELASAN PARAMETER UTAMA (Vx, Vy, Vw, LIMIT, KETERANGAN)
------------------------------------------------------------------------------

1. Vx (Sumbu X / Maju-Mundur / Absolut X):
   - Pada PWM & Local Odometry: Kecepatan relatif maju (+) atau mundur (-).
   - Pada Find Coordinate & Global Odometry: Titik koordinat target X di lapangan Pygame.

2. Vy (Sumbu Y / Geser Kanan-Kiri / Absolut Y):
   - Pada PWM & Local Odometry: Kecepatan relatif geser kanan (+) atau geser kiri (-).
   - Pada Find Coordinate & Global Odometry: Titik koordinat target Y di lapangan Pygame.

3. Vw (Rotasi / Heading Angle):
   - Pada PWM & Local Odometry: Kecepatan putar rotasi (+/-).
   - Pada Rotasi / Find Coordinate / Global Odometry: Target sudut heading robot (0° - 360°).

4. Tipe Limit & Nilai Limit:
   - Waktu (s)               : Berjalan selama durasi X detik.
   - Jarak (px / mm)         : Berjalan sejauh X pixel/mm.
   - Sudut (°)               : Berputar hingga akumulasi sudut mencapai X derajat.
   - Sensor Garis            : Berjalan terus hingga sensor mendeteksi garis putih.
   - Sensor Jarak Depan (mm) : Berjalan hingga jarak ke dinding depan <= X mm.
   - Sensor Jarak Kiri (mm)  : Berjalan hingga jarak ke dinding kiri <= X mm.

5. Keterangan (Parameter Kontekstual):
   - Diisi string label Stand (misal: "P1 S1"), slot Almari (misal: "A1 S3"), 
     nama warna target ("RED", "GREEN", "BLUE"), atau nomor urutan lompatan (misal: "4").

------------------------------------------------------------------------------
C. CONTOH PENGISIAN PARAMETER & EFEK GERAKAN (COMMANDS)
------------------------------------------------------------------------------

1. Local Odometry (Pergerakan Relatif Robot)
   - Deskripsi: Menggerakkan robot relatif terhadap arah posisi dirinya sendiri.
   - Contoh Input:
     * Nama       : local odometry (atau "maju")
     * Vx         : 10.0
     * Vy         : 0.0
     * Vw         : 0.0
     * Limit Type : Waktu (s)
     * Limit Val  : 2.0
     * Keterangan : -
   - Apa Yang Terjadi: 
     Robot bergerak MAJU lurus searah hadap dirinya sendiri dengan kecepatan 10 
     selama 2.0 detik, lalu menghentikan roda dan me-reset odometry lokal.

2. Global Odometry (Pergerakan Absolut Lapangan)
   - Deskripsi: Menggerakkan robot ke posisi koordinat absolut lapangan.
   - Contoh Input:
     * Nama       : global odometry
     * Vx         : 500.0
     * Vy         : -200.0
     * Vw         : 90.0
     * Limit Type : Odometry
     * Limit Val  : 0.0
     * Keterangan : -
   - Apa Yang Terjadi: 
     Robot bergerak menuju titik X=500, Y=-200 di lapangan Pygame dan memutar badannya 
     hingga menghadap sudut 90° (tegak lurus), tidak peduli posisi/sudut awal robot.

3. PWM (Open Loop / Kecepatan Manual)
   - Deskripsi: Daya murni ke motor tanpa koreksi PID posisi.
   - Contoh Input 1 (Maju Waktu):
     * Nama       : pwm
     * Vx         : 10.0
     * Vy         : 0.0
     * Vw         : 0.0
     * Limit Type : Waktu (s)
     * Limit Val  : 1.5
     * Keterangan : -
     * Apa Yang Terjadi: Motor diberi persentase daya PWM 10% melaju ke depan 
       selama 1.5 detik.
   - Contoh Input 2 (Geser Kiri Sampai Garis):
     * Nama       : pwm
     * Vx         : 0.0
     * Vy         : -20.0
     * Vw         : 0.0
     * Limit Type : Sensor Garis
     * Limit Val  : 0.0
     * Keterangan : -
     * Apa Yang Terjadi: Robot bergeser ke KIRI dengan daya PWM 20% terus-menerus 
       sampai sensor garis kiri/kanan mendeteksi garis putih, lalu berhenti seketika.

4. Delay (Menunggu)
   - Deskripsi: Menghentikan pergerakan robot selama durasi waktu tertentu.
   - Contoh Input:
     * Nama       : delay
     * Vx         : 0.0
     * Vy         : 0.0
     * Vw         : 0.0
     * Limit Type : Waktu (s)
     * Limit Val  : 3.0
     * Keterangan : Jeda Persiapan
   - Apa Yang Terjadi: 
     Robot berhenti total (kecepatan 0) selama 3.0 detik sebelum melanjutkan ke langkah berikutnya.

5. Find Coordinate (Navigasi A-Star / Autopilot)
   - Deskripsi: Navigasi pintar otomatis menghindari rintangan/tembok menuju target.
   - Contoh Input:
     * Nama       : find coordinate
     * Vx         : -660.0
     * Vy         : -100.0
     * Vw         : 180.0
     * Limit Type : Navigasi A*
     * Limit Val  : 0.0
     * Keterangan : Menuju Stand P1
   - Apa Yang Terjadi: 
     Algoritma A* menghitung rute jalan bebas rintangan. Robot berjalan sendiri 
     menuju X=-660, Y=-100 dan berputar hingga sudut 180° menghadap stand.

6. Reset Coordinate / Reset Odometry
   - Deskripsi: Mengatur ulang titik acuan (origin 0 cm) kalkulasi odometry robot.
   - Contoh Input:
     * Nama       : reset coordinate
     * Vx=0, Vy=0, Vw=0, Limit Type=Reset Odom, Limit Val=0
   - Apa Yang Terjadi: 
     Posisi robot saat ini dijadikan titik acuan (0,0) baru untuk perhitungan Odometry.

7. Balance (Penyesuaian Sensor ke Tembok/Garis)
   - Deskripsi: Menyetarakan jarak dan sudut robot terhadap dinding sejauh ~5cm.
   - Contoh Input:
     * Nama       : balance depan kiri
     * Vx=0, Vy=0, Vw=0, Limit Type=Waktu (s), Limit Val=2.0
   - Apa Yang Terjadi: 
     Sensor jarak depan dan kiri aktif membaca tembok. Robot menyesuaikan posisi 
     dan kemiringan badan secara otomatis agar jarak ke dinding depan & kiri tepat ~5cm 
     serta tegak lurus sempurna.

8. Ambil Kubus (Grab Sequence)
   - Deskripsi: Mengambil kubus dari stand dan menyimpannya di storage carousel.
   - Contoh Input:
     * Nama       : ambil kubus
     * Vx=0, Vy=0, Vw=0, Limit Type=Waktu (s), Limit Val=2.0
     * Keterangan : P1 S1
   - Apa Yang Terjadi: 
     Robot menghentikan roda, menjulurkan mekanisme gripper ke stand P1 S1, 
     menyedot/menjepit kubus, menarik arm kembali, memutar carousel storage, 
     dan menyimpan kubus di slot kosong.

9. Taruh Kubus (Drop Sequence)
   - Deskripsi: Meletakkan kubus dari storage ke Rak Almari.
   - Contoh Input:
     * Nama       : taruh kubus
     * Vx=0, Vy=0, Vw=0, Limit Type=Taruh Kubus
     * Limit Val  : 2.0  (Default slot storage 2)
     * Keterangan : A1 S3 (RED di S2)
   - Apa Yang Terjadi: 
     Carousel memutar slot S2 (yang berisi kubus MERAH) ke posisi depan, arm gripper 
     mendorong kubus keluar dan meletakkannya presisi di Rak Almari A1 S3, 
     lalu menarik arm kembali.

------------------------------------------------------------------------------
D. CONTOH LOGIKA PINTAR (SMART LOGIC & DECISION MAKING)
------------------------------------------------------------------------------

1. apakah ditaruh? (Cek Warna Storage & Taruh Otomatis)
   - Contoh Input:
     * Nama       : apakah ditaruh?
     * Limit Type : Cek Taruh
     * Keterangan : A1 S3
   - Apa Yang Terjadi:
     * Program membaca target warna di Almari A1 S3 (misal butuh MERAH).
     * Program memeriksa 8 slot storage robot. 
     * JIKA KUBUS MERAH ADA di Storage (misal Slot S2): Langkah "taruh kubus" di bawahnya 
       otomatis diisi slot S2 (limit_val: 2.0) dan robot menaruh kubus MERAH ke Almari A1 S3.
     * JIKA KUBUS MERAH TIDAK ADA / Target Almari Kosong: Langkah "taruh kubus" di bawahnya 
       otomatis diubah menjadi "delay 0.1s" dengan keterangan "Dilewati (Tidak Ada Kubus RED di Storage)".

2. apakah full? / full? (Cek Storage Penuh & Lompat Urutan)
   - Contoh Input:
     * Nama       : apakah full?
     * Limit Type : Cek Full/Target
     * Keterangan : 4  (artinya Lompat ke Urutan Kombinasi #4 "Taruh ke Almari")
   - Apa Yang Terjadi:
     * JIKA STORAGE PENUH (8 kubus) ATAU Target Warna Almari sudah lengkap di storage:
       Sekuens LANGSUNG MELOMPAT (jump) mengeksekusi Urutan Kombinasi #4 
       dan melewati (skip) semua langkah di bawahnya.
     * JIKA BELUM PENUH: Sekuens berlanjut normal ke langkah di bawahnya.

3. apakah diambil? (Cek Kebutuhan Target & Ambil Otomatis)
   - Contoh Input:
     * Nama       : apakah diambil?
     * Limit Type : Cek Ambil
     * Keterangan : P1 S1
   - Apa Yang Terjadi:
     * Program membaca warna kubus di stand P1 S1 dari memori scan vision.
     * JIKA WARNA DIBUTUHKAN Almari & Storage belum penuh: Langkah berikutnya 
       otomatis diubah menjadi "ambil kubus".
     * JIKA TIDAK DIBUTUHKAN / Storage Penuh: Langkah berikutnya otomatis 
       diubah menjadi "delay 0.1s" (dilewati).

4. Scan Stand / Scan Almari / Scan Target
   - Contoh Input:
     * Nama       : scan stand
     * Limit Type : Scan Stand
     * Keterangan : P1
   - Apa Yang Terjadi:
     * Robot berhenti (VEL 0 0 0), jendela kamera vision aktif memotong frame 
       ultra-narrow (36px), melakukan scanning warna HSV kubus pada Stand P1, 
       menyimpan hasil ke tabel memori real-time, lalu menutup jendela kamera.

------------------------------------------------------------------------------
E. FITUR GUI CONTROLLER & PENGELOLAAN SEKUENS
------------------------------------------------------------------------------

1. Tombol Copy (Salin Kombinasi & Gerakan):
   - Klik tombol "Copy" pada Urutan Kombinasi (Level 1), Antrean Kombinasi (Level 2), 
     atau Detail Gerakan (Level 3) untuk menduplikasi item terpilih secara langsung.

2. Stand & Target Memory Real-Time:
   - Visualisasi tabel memori real-time hasil scanning Ruangan P (P1-P3), 
     Gudang A (A1-A2), dan Target Almari.

3. Mulai dari Pilihan (Start From):
   - Klik kanan / pilih langkah pada tabel sekuens lalu klik "Start From" 
     untuk mengeksekusi robot mulai dari posisi/langkah tersebut.

4. Reset Robot & Reset Storage:
   - Tombol pintas untuk me-reset posisi robot ke HOME (0,0) atau 
     mengosongkan isi 8 slot storage carousel secara paksa.

5. Telemetri Real-Time:
   - Umpan balik langsung koordinat X/Y, sudut heading, jarak tempuh, 
     status sensor garis, dan visualisasi 8 slot storage.
