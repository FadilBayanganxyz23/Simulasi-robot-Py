# ==============================================================================
# BUKU PANDUAN FITUR - SIMULASI ROBOT OMNI & GUI CONTROLLER
# ==============================================================================

Berikut adalah daftar lengkap fitur-fitur, pergerakan, dan pemrosesan otomatis 
yang bisa dilakukan oleh robot di dalam simulasi, serta penjelasan fungsi-fungsinya.

------------------------------------------------------------------------------
A. PERINTAH GERAKAN (COMMANDS)
------------------------------------------------------------------------------

1. Local Odometry (Pergerakan Relatif)
   - Deskripsi: Menggerakkan robot berdasarkan koordinat dirinya sendiri (lokal).
     Vx positif akan membuat robot melaju ke depan, Vy positif membuat robot 
     bergeser ke kanan, dan Vw mengatur rotasi.
   - Nama Gerakan: "local odometry", "maju", "geser", "rotasi".

2. Global Odometry (Pergerakan Absolut)
   - Deskripsi: Menggerakkan robot berdasarkan koordinat lapangan (global Pygame).
     Arah atas/bawah/kiri/kanan lapangan akan selalu tetap, tidak peduli ke arah 
     mana robot saat ini menghadap.
   - Nama Gerakan: Harus mengandung kata "global odometry".

3. PWM (Open Loop / Kecepatan Manual)
   - Deskripsi: Menggerakkan motor tanpa membaca sensor posisi (tanpa PID lokal).
     Angka Vx, Vy, Vw akan langsung dikonversi menjadi persentase PWM murni.
   - Nama Gerakan: Harus mengandung kata "pwm".

4. Delay (Menunggu)
   - Deskripsi: Menghentikan pergerakan robot selama beberapa waktu.
     [MODIFIKASI]: Jika langkah ini merupakan hasil turunan dari "apakah ditaruh?" 
     yang tidak menemukan warna kubus cocok, delay akan otomatis diisi 0.1s 
     dengan keterangan "Dilewati".
   - Nama Gerakan: Harus mengandung kata "delay".

5. Find Coordinate (Navigasi A-Star / Autopilot)
   - Deskripsi: Menginstruksikan robot untuk secara otomatis mencari rute jalan 
     dan menghindari tembok menuju titik koordinat X (Vx) dan Y (Vy), sambil 
     menyesuaikan putaran (Vw).
   - Nama Gerakan: Harus mengandung kata "find coordinate" atau "navigasi".

6. Reset Coordinate / Reset Odometry
   - Deskripsi: Mengatur ulang origin kalkulasi jarak di dalam game (0 cm).
   - Nama Gerakan: "reset coordinate" atau "reset odometry".

7. Balance (Penyesuaian Sensor ke Tembok/Garis)
   - Deskripsi: Menyetarakan jarak dan sudut robot terhadap dinding sejauh 5cm 
     agar robot berada dalam posisi tegak lurus sempurna.
   - Nama Gerakan: "balance depan", "balance kiri", "balance depan kiri".

8. Ambil Kubus (Grab Sequence)
   - Deskripsi: Robot secara otomatis mendekati stand kosong/berisi di depannya, 
     menjulurkan gripper, mengambil kubus, dan menyimpannya ke slot storage carousel.
   - Nama Gerakan: "ambil kubus", "grab".

9. Taruh Kubus (Drop Sequence)
   - [MODIFIKASI & DIPERBARUI]:
     * Robot akan membaca seluruh 8 slot isi storage 1 per 1 dan mencocokkannya 
       dengan warna target yang diminta di Keterangan / target memory.
     * Rak Carousel storage diputar otomatis hingga slot yang berisi kubus cocok 
       berada di posisi depan.
     * Gripper meletakkan kubus secara presisi pada posisi pusat Stand / Rak Almari (`ALMARI_V`).
     * GUI Controller mengunci penungguan hingga animasi drop SELESAI di simulator 
       sebelum melepaskan sekuens ke langkah berikutnya.
   - Nama Gerakan: "taruh kubus", "drop".

------------------------------------------------------------------------------
B. FITUR BARU & LOGIKA LOGIKA PINTAR (NEW FEATURES)
------------------------------------------------------------------------------

1. apakah ditaruh? (Cek Warna Storage & Taruh Otomatis)
   - [FITUR BARU]:
     * Memeriksa slot target di Almari (misal `A1 S3`, `A1 S2`, `A1 S1`) atau nama warna (`RED`, `GREEN`, `BLUE`).
     * Membaca seluruh isi 8 slot storage robot 1 per 1.
     * Jika kubus warna yang cocok ditemukan di storage (misal RED ada di Slot S2), 
       langkah `taruh kubus` selanjutnya otomatis diubah nilainya ke slot S2 (`2.0`) 
       dan robot menaruhnya ke Almari.
     * Jika target slot Almari bernilai `EMPTY` (tidak butuh kubus) atau warna yang 
       dicari tidak ada di storage, langkah `taruh kubus` otomatis di-skip (diganti `delay 0.1s`).

2. apakah full? / full? (Cek Storage Penuh & Lompat Urutan)
   - [FITUR BARU]:
     * Memeriksa apakah kapasitas storage robot telah penuh (8 kubus).
     * Membandingkan secara otomatis jumlah warna kubus di storage dengan total 
       kebutuhan warna pada Target Almari.
     * Jika Storage Penuh ATAU Target Terpenuhi: Sekuens otomatis melompat (*jump*) 
       ke Urutan Kombinasi #4 ("taruh ke almari" / urutan yang ditentukan di Keterangan).
     * Jika Belum Penuh: Sekuens berlanjut ke langkah berikutnya tanpa melompat.

3. Scanning Stand Ultra-Narrow Crop (Visi 36px)
   - [FITUR BARU]:
     * Pemotongan frame kamera vision dipersempit menjadi 36px x 90px persis pada 1 garis stand.
     * Memastikan 100% tidak ada kebocoran warna dari kubus di stand tetangga.

4. Modul Terpisah Vision & Navigasi
   - [FITUR BARU]:
     * `simulator/vision.py`: Pemrosesan OpenCV HSV & scanning warna.
     * `simulator/navigation.py`: Pathfinding A* & Pure Pursuit.

------------------------------------------------------------------------------
C. TIPE LIMIT (BATAS KONDISI)
------------------------------------------------------------------------------

1. Waktu (s)   : Menjalankan perintah selama X detik.
2. Jarak (px)  : Menjalankan perintah sejauh X pixel.
3. Sudut (°)   : Berputar hingga target X derajat tercapai.
4. Sensor Garis: Berjalan hingga Sensor Garis mendeteksi garis putih.

------------------------------------------------------------------------------
D. FITUR GUI CONTROLLER & PENGELOLAAN SEKUENS
------------------------------------------------------------------------------

1. Tombol Copy (Salin Kombinasi & Gerakan)
   - [FITUR BARU]: Tombol "Copy" tersedia di Level 1 (Urutan Kombinasi), 
     Level 2 (Antrean Kombinasi), dan Level 3 (Detail Gerakan) untuk menduplikasi 
     item dengan satu kali klik.

2. Stand & Target Memory Real-Time
   - Menampilkan visualisasi tabel memori hasil scanning Ruangan P (P1-P3), 
     Gudang A (A1-A2), dan Target Almari.

3. Mulai dari Pilihan (Start From)
   - Menjalankan sekuens dari tahapan tertentu yang disorot user.

4. Reset Robot & Reset Storage
   - Reset posisi robot ke HOME (0,0) atau Reset paksa isi 8 slot storage carousel.

5. Telemetri Real-Time
   - Menampilkan posisi X/Y, heading sudut, jarak tempuh, sensor garis, dan 8 slot storage.
